# 来源与风险

- Trending、Explore 和社区讨论只用于发现，确定性事实回到 GitHub 官方页面核验。
- 入选项目必须核验明确用途、README、许可证、最近提交、最近发布、平台、安装门槛、受众和风险；至少深度核验 8 个候选。
- 未发现许可证时不得暗示可以自由商用。
- Star、Release 和 Commit 等动态信息记录核验时间，发布前再次复核。
- 官方截图只有在来源、许可证和使用许可均已核验时才能标记 `approved`；Logo、社交预览图和授权未知图片不得自动进入正文。
- 风险区分 `reader_visible`：影响普通读者决策的重要风险进入读者卡，其余完整审核信息留给下游运营审核台。
