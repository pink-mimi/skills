# AI 新发现来源与风险

## 优先来源

- 官方博客、发布页、产品文档、价格页和变更日志。
- 论文页、arXiv、Hugging Face model card、GitHub README 和 Release。
- 主流技术媒体和社区讨论只用于发现线索，不作为确定性事实的唯一来源。

## 必核字段

- 名称、类型、官方链接、发布时间或发现时间。
- 用途、适合人群、使用门槛、费用或额度限制。
- 隐私、安全、版权、地域可用性、稳定性和宣传夸大风险。
- 核验状态为 `verified` 或 `partial` 时，至少一个官方来源必须记录核验时间 `verified_at`。
- 声称已实测时，必须保留可追溯的 `experience_notes`、`test_notes` 或 `evidence`。

## 写作边界

- 没有可追溯实测记录时，不得写“我试了”“体验很好”等亲历判断。
- 官方来源缺失或关键事实冲突时，保留候选但标记 `needs_review`。
- 与医疗、金融、法律或公共安全相关的 AI 应用必须提高风险等级，并等待人工判断。
