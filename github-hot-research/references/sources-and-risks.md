# 来源与风险

- 默认来源为 GitHub Trending weekly 页面前 10 名：`https://github.com/trending?since=weekly`。榜单顺序是本 Skill 的发布顺序，不得用搜索 API、评分、分类平衡或历史去重替换。
- GitHub API、README、Release、Commit、LICENSE 和项目主页只用于补充核验；本周热度证据来自周榜页面和采集时间。
- 入选项目必须核验明确用途、README、许可证、最近提交、最近发布、平台、安装门槛、受众和风险；前 10 名都要保留核验记录。
- 未发现许可证时不得暗示可以自由商用。
- Star、Release 和 Commit 等动态信息记录核验时间，发布前再次复核。
- README/docs/homepage 图片先作为候选；badge、Logo、头像、小图标、社交预览和装饰图直接排除。只有 repo 内图片、来源和许可证均已核验时才能标记 `approved`；外站图片和授权未知图片只能标记 `review_required`。
- 风险区分 `reader_visible`：影响普通读者决策的重要风险进入读者卡，其余完整审核信息留给下游运营审核台。
