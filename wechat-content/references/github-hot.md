# GitHub 热门栏目模板

- 栏目标识使用“开源坐标”。
- 开头说明热度与长期价值的区别，不描述机械搜索过程。
- schema v2 每个项目使用轻量读者卡：编号与类别、一句话推荐、用途摘要、3 个亮点、适用人群、上手难度、语言/Star/Fork，以及官方地址。
- 周增 Star 为 `null` 时整项省略，绝不显示为 0。
- 完整 README、许可证、Commit、Release、维护状态、指标核验时间、内部风险、证据、未入选原因和图片审核信息放在复制区外的运营审核台。
- 没有明确许可证时必须原样提示，不把开源等同于可自由商用。
- `reader_visible: true` 的重要风险进入正文；内部审核风险不得进入复制区。
- 结尾观察开发者正在解决的问题，并邀请读者选择想尝试或推荐的项目。
- 每个项目必须恰好有一张正文图。优先使用来源和授权均已核验且获批的官方真实截图；其次使用依据已核验用途生成的 Image2 示意图；最后使用本地项目卡片。
- 正文图表达项目用途和代码连接，不虚构真实产品界面、Logo、文字或数据。
